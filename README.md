# Xi Design Web

华数设计 (Huashu Design) 网页版展示站。

## 在线预览

直接打开 `index.html` 即可浏览。

## 特性

- 🏛️ 5 大设计流派 · 20 条设计哲学
- 🎬 6 大核心能力展示
- 📐 完整工作流说明
- 📱 响应式设计（移动端适配）
- ✨ 滚动动画 + 交互效果

## 技术栈

- 纯 HTML/CSS/JS，零依赖
- Google Fonts (Inter, Source Serif 4, Noto Serif SC, JetBrains Mono)
- CSS Custom Properties
- Intersection Observer API
